STEP 3: DEPLOY TO VERCEL (5 min)
─────────────────────────────────

1. Create a FREE GitHub account: https://github.com/signup

2. In this folder, run:

   git branch -M main
   git push -u origin main

3. Go to Vercel: https://vercel.com

4. Click "New Project" → "Import Git Repository"

5. Paste your GitHub URL from step 2

6. Click "Import" then "Deploy"

Wait 60 seconds... and BOOM! 🚀 Your app is live on the internet!

Vercel will give you a URL like:

TROUBLESHOOTING
───────────────

Problem: Blank page / Nothing shows up
→ Open DevTools (F12) → Console tab → look for red errors

Problem: Can't connect to database
→ Run: node test-supabase.js
→ Follow SETUP-DATABASE.md again

Problem: "npm: command not found"
→ You need Node.js: https://nodejs.org/
→ Install it, then try again

Problem: Vercel won't deploy
→ Check you pushed to GitHub first!
→ Check Vercel dashboard → Deployments → see the error logs
