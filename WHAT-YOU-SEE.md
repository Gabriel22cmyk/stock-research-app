## Features You'll See

### 1. Stock Cards
- Stock symbol (AAPL, MSFT, etc.)
- Company name
- Current price (where it trades now)
- Target price (where we think it's going)
- Potential upside (the percentage gain)
- "View Details" button
- Star icon (save to watchlist)

### 2. Detail Modal
- Recommendations from analysts
- Rating (Strong Buy, Buy, etc.)
- Recommendation text
- Date of recommendation
- Recent price history

### 3. Watchlist
- All your saved stocks
- Filled stars (easy to remove)
- Same card layout as home page

### 4. Navigation
- Click tabs to switch between pages
- Quick access to watchlist count
- Smooth animations

---

## Colors You'll See

- **Blue** (#0066cc): Main brand color, stock symbols
- **Gold** (#ffc107): Target prices, filled stars
- **Green**: Positive price movements
- **Red**: Negative price movements
- **Gray**: Less important text
- **White**: Cards and backgrounds
- **Light gray**: Hover effects

## Interactions

### Adding to Watchlist
```
Click ☆ → ★ (filled in yellow) → Stock saved!
```

### Removing from Watchlist
```
Click ★ → ☆ (outline only) → Stock removed!
```

### View Details
```
Click [View Details] → Modal pops up → Read recommendations → Click ✕ to close
```

### Switch Pages
```
Click [Watchlist] tab → See only your saved stocks
Click [Latest Picks] tab → See all recommendations
```
